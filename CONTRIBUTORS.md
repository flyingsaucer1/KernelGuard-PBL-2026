# Team contributions and responsibilities

KernelGuard is a four-member project. The responsibility areas below describe the
team's project allocation and the parts each member should be able to explain and
maintain. Detailed file lists are linked in the last column.

| Member | Project area | Detailed record |
| --- | --- | --- |
| Arshpreet Singh | Linux Audit collection, parsing, host inventory, and collector operation | [Arshpreet](docs/contributions/ARSHPREET.md) |
| Mohd Ahmed Khan | Relational schema, persistence, transactions, and database integration | [Ahmed](docs/contributions/AHMED.md) |
| Ankit | Detection policies, evidence evaluation, and rule tests | [Ankit](docs/contributions/ANKIT.md) |
| Mohd Shoaib | Dashboard, authentication, device actions, and alert review | [Shoaib](docs/contributions/SHOAIB.md) |

Some files are shared across these areas. The [team file ownership record](docs/contributions/README.md)
identifies primary and shared responsibilities. These records document project roles;
they do not replace Git commit history or prove that an individual authored every
line in a listed file. The existing commits retain their original author information.
